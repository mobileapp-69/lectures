# Getting Started - Terminal

- Check installation
  - `flutter doctor`
- Check device/emulator
  - `flutter emulators`
  - `flutter emulator --launch <emulator id>`
  - `flutter devices`
- Create a new project
  - `flutter create <project name>`

---

# Getting Started - VSCode

- Settings `Dart: Hot Reload On Save` > `All`
- Ctrl + P > `Flutter: Select Device` > `<device>`

---

# Code Formatting

`analysis_options.yaml`

```yaml
formatter:
  trailing_commas: preserve
```

_This setting preserves trailing commas and format arguments in a separate line. This is easier to read._

---

# Two ways of Running the App

- Terminal
  - `flutter run`
- Debugging in VSCode
  - Open `main.dart`
  - Press `F5` or `Run > Start Debugging`

---

# Difference between Two Ways of Running the App

| Feature                       | Terminal  | Debugging in VSCode                                           |
| ----------------------------- | --------- | ------------------------------------------------------------- |
| Hot reload enabled by default | No        | Yes                                                           |
| Trigger hot reload            | Press `r` | Automatically when you save the file                          |
| Trigger hot restart           | Press `R` | Press `Ctrl + Shift + F5` or select `Run > Restart Debugging` |

---

# Set Breakpoint in VSCode

- Open `main.dart`
- Set a breakpoint.
  - Make sure that the breakpoint has debuggable code.
